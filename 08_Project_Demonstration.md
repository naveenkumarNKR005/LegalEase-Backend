# Phase 8 — Project Demonstration

## Suggested 2–3 minute demo flow

1. Open LegalEase.
2. Show the title and legal-review disclaimer.
3. Select a document type.
4. Select English.
5. Enter sample information.
6. Click Generate Document.
7. Show the generated draft.
8. Edit one field if required.
9. Download DOCX.
10. Change language to Tamil and generate another draft.
11. Show Hindi as the third supported language.
12. Briefly show the GitHub repository structure.
13. Explain that Gemini is optional and the application has a template fallback.

## Demo statement

"LegalEase is an AI-assisted multilingual legal-document drafting prototype. It accepts simple user information, generates a structured draft using Gemini when available, provides a template fallback, allows editing, and exports the result as DOCX or PDF. The system is designed for educational purposes and requires professional legal review before actual use."
