# Phase 7 — Project Documentation

## Project title
LegalEase — AI-Assisted Multilingual Legal Document Generator

## Objective
To create a simple AI-assisted tool that produces structured drafts from user-provided information.

## Scope
The prototype covers common document categories and multilingual drafting. It is not a legal-advice system.

## Limitations
AI output can contain errors and may not match the laws or requirements of a specific jurisdiction. Human/legal-professional review is required.

## Conclusion
LegalEase demonstrates how generative AI, APIs and document automation can be combined into a practical legal-tech prototype.
