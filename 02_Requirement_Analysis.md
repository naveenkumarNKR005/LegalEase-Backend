# Phase 2 — Requirement Analysis

## Functional requirements
1. User selects a document type.
2. User selects a language.
3. User enters parties, address, purpose and terms.
4. System validates required fields.
5. AI generates a draft when an API key is available.
6. System provides a deterministic template fallback.
7. User can edit the generated text.
8. User can download DOCX and PDF.
9. Backend exposes health and generation endpoints.

## Non-functional requirements
- Simple UI
- Mobile-friendly workflow
- Secret-safe API key handling
- Clear legal disclaimer
- Modular Python code
- Easy deployment
